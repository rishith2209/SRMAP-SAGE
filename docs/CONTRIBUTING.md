# Contributing to SRMAP SAGE

We welcome contributions from SRMAP students, alumni, faculty, and open-source contributors!

## How You Can Help
1. **Verified Knowledge Submissions**:
   - Provide official handbooks, regulation circulars, or placement brochures.
   - Update cabin locations or faculty directory information with evidence.
2. **Feature Development**:
   - Improve the intent classifier in `src/engines/router_engine.py`.
   - Add new adaptive UI card types in `apps/web/src/components/adaptive/`.
   - Enhance the campus navigation pathfinding algorithms.
3. **Bug & Hallucination Reports**:
   - If SAGE gives an outdated answer, submit an issue via the [Content Correction Template](../.github/ISSUE_TEMPLATE/content_correction.md).

## Verification Rules
Every submission altering SRMAP-specific knowledge must include an official source URL, document scan, or verifiable circular reference. Ungrounded contributions will be closed.
